# Storefront UI Exercise

This repository is a small static front-end exercise modeled on an online shopping storefront. It contains HTML, CSS, and browser-side JavaScript; it does not include a server, product database, checkout, or payment processing.

## Run locally

Open `index.html` in a modern browser. The page references externally hosted images and Font Awesome, so an internet connection is needed for all visuals to load.

## Project files

- `index.html` contains the page structure.
- `style.css` contains the styles.
- `javascript.js` and `todayDeal.js` contain the browser-side scripts.
